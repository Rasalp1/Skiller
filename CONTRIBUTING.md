# Contributing to Skiller

Thanks for contributing. Skiller changes local agent configuration, so keep changes narrowly scoped and do not add real skills, credentials, or machine-specific paths to fixtures.

## Before opening a pull request

1. Use macOS 14 or later with Swift 6.
2. Run `swift test` and `swift build -c release`.
3. Add or update tests for parsing, discovery, or file-operation behavior.
4. Explain any filesystem or configuration compatibility implications.

Report vulnerabilities through [SECURITY.md](SECURITY.md), not a public issue.
